Менеджер Simple GUI был выделен из проекта https://github.com/ua1arn/hftrx/tree/develop в качестве внешнего сабмодуля. Simple GUI предназначен для мобильных\портативных проектов, организует простой экранный интерфейс с поддержкой ввода через тачскрин. Не имеет излишней усложненности, как, например, lvgl. Двухоконная организация интерфейса, основное окно всегда развернуто на весь экран, присутствует ряд нижних кнопок, по умолчанию их 9. Основное окно с прозрачным фоном для возможности наложения на ранее сформированный интерфейс. Второе окно открывается при взаимодействии с объектами основного окна или при запросах базовой программы. Основные интерактивные объекты, реализуемые фреймворком - кнопка, метка, слайдер, текстовое поле, сенсорное поле. На их основе возможна реализация разнообразных интерфейсов, например, экранная qwerty клавиатура (в проекте hftrx  - window_kbd_test_process), эквалайзер (window_af_eq_process). Репозиторий https://github.com/RA4ASN/Simple-GUI-example - простой пример использования Simple GUI в среде Linux. Simple GUI рассчитан на разрешение экрана 800х480, поскольку создавался для hftrx, но Simple-GUI-example реализует пример масштабирования до размеров физического экрана. Взаимодействие между framework и user частями GUI реализовано посредством очереди сообщений, которыми framework и user могут обмениваться друг с другом. Проект в стадии развития.
